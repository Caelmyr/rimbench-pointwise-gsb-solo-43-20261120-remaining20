# RimBench 转台轮廓计量

RimBench 从固定相机的背光投影恢复近似凸截面，供工位操作人员检查尺寸、形位、公差和复测记录。

## 启动

```sh
docker compose up -d --build
docker compose ps
```

浏览器打开 <http://127.0.0.1:18946>。服务使用本机回环地址和独立的 `solo46-rimbench_inspection-data` 卷。停止服务时执行 `docker compose stop`。需要另一端口时设置 `RIMBENCH_PORT`。健康接口是 `/api/health`。

也可以用 Python 3.11 环境安装固定依赖 `python -m pip install -r requirements.txt` 后运行 `python app.py`。默认地址为 `127.0.0.1:18946`，数据位于当前目录下的 `.rimbench`。使用 `HOST`、`PORT` 和 `RIMBENCH_DATA` 可调整运行设置。

## 从采集到归档

1. 从侧栏打开「阶梯衬套演示」或「偏心导套演示」，或者新建样件并导入固定画幅的角度影像。内置样件、空场复检和九点标板演示均由程序合成。
2. 在「采集与标定」设置影像角度、参与状态、亚像素位移和曝光补偿。可上传空场参考，检查背光网格，调整分割配方。按标尺距离填写轴参数，或用两个暗圆靶估计后确认。
3. 在「截面测量」输入物理高度和方向。角度影像显示原图、轮廓和当前截线。截面支持查看外包络、内包络、单角度支撑证据、轴向尺寸曲线和缺测高度。可下载 CSV、带物理比例的 SVG，或打开可打印检验报告。
4. 在「公差量规」为选定高度与方向设置标称值和上下限。区间全部在公差内、全部超差、相交、缺测分别给出状态；挂起记录影响放行状态。
5. 在「形位与质检」执行以下核验。已关联样件影像的核验可以将本次结果和采集版本一起归档，再下载 CSV 或 JSON。
6. 在「快照与复测」保存截面、可选轴向曲线及公差结果。后续测量可以比较同高截面或具有重叠且连续有效高度的曲线。整个活动样件与影像可以通过侧栏与页头交换 ZIP；工位上的测量快照和质检归档随本机数据库保存。

| 形位和质检项目 | 输入与结果 |
| --- | --- |
| 截面圆拟合 | 一处轴向高度与指定圆心。显示拟合直径、拟合残差、径向极差和等角度径向残差图。 |
| 轴向形位 | 一段被测高度。可用转台轴或对另一段拟合基准线，输出逐截面圆心、横向偏距、中心线偏离和基准外推状态。 |
| 套环包络 | 内径、偏置、最小余量及抽样高度。用内外轮廓与标尺误差给出区间、抽样段判读及限制点。 |
| 周向形状 | 选定周期与轴向范围。角度支持充分时输出幅值与相位，跨过缺测时重新开始相位轨迹。 |
| 成像边缘 | 截面高度和每侧取样长度。原图亮度、反差、10%–90%过渡宽度和异常标记可逐端查看。选择一张影像时附像素轨迹。 |
| 投影复核 | 两张近似同向或相差180°的独立原图。按第一张的物理方向比较逐高左右端、宽度和中心偏差。 |
| 光场复检 | 当前空场和新拍空场。全图增益与局部异常分别显示，并给出原图和异常分区图。 |
| 九点标板 | 三行三列圆点原图、已知步距和四个估计角点。检查横纵比例、局部点距、定位残差、角度和各点边缘清晰度。 |

合成阶梯衬套在高度 22 mm、方向 0°时，方向宽度约 33.43 mm，共有 11 张有效影像。光场局部异常样例应出现两块异常区。「九点标板」的畸变样例保留九个有效圆点，中央圆点的定位残差最大。

## 影像、容量和测量边界

单页 PNG、JPEG、TIFF、BMP 支持 8 位灰度、16 位灰度及彩色影像。每张边长至少 24 px、至多 600 万像素，单文件及其无损规范化副本各至多 18 MiB。一个样件至多保留 48 个角度、24 个量规、40 个测量快照与 30 个核验归档。工作站上限为 80 个样件，单个交换包上限 150 MiB。工作站允许两个重图像请求并行。轴向、形位与间隙计算各自限制采样点数与参与角度的乘积，页面会提示收窄输入。

转轴应与样件轴向相符，相机与转台位置在一组采集中保持固定。尺寸来自有限角度的凸外轮廓，内孔、凹槽和被材料遮蔽的曲面没有对应的直接观测。照明、分割、视角间隔、支撑异常与标尺都影响结果；角度支撑欠闭合或相互冲突时，页面报告当前量测状态。拟合与包络为工位比较工具；沿轴测量结果落在所抽样高度，不能替代连续三维轮廓或正式量具校验。
